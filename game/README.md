# Рівень 1 — «Кум шукає Куму»

Грабельний прототип першої локації (`Теплий Мілководь` з `docs/03-levels.md`),
зроблений як святкове привітання. Один файл, без збірки: відкрити
`level-01-kum-i-kuma.html` у браузері.

## Що всередині

- **Three.js r128** з CDN, уся інша логіка — інлайн, без залежностей.
- **Зелений Кум** — гравець. **Рожева Кума** чекає на острові за очеретяною огорожею.
- **12 росяних кристалів.** Кожні три піднімають з води один листок стежки —
  це і є ворота прогресу з дизайн-документа: не ключ, а вода.
- **Блимка** — світлячок-супутник, летить у бік найближчого незібраного кристала.
- Фінал: жабки зустрічаються, летять серця, з'являється привітання.

## Керування

| Дія | Клавіатура | Телефон |
|---|---|---|
| Рух | `WASD` / стрілки | джойстик у лівій половині екрана |
| Стрибок | `Пробіл` | кнопка «Стрибок» |
| Заряджений стрибок | утримувати `Пробіл` | утримувати кнопку |
| Камера | тягнути мишею | тягнути праву половину |

## Реалізовані механіки з GDD

- Заряджений стрибок з присіданням і squash-stretch (`01-concept.md`, §2.1)
- Плавання без кисневого таймера — у воді не тонуть (§2.6)
- Блимка як навігація (§1)
- Ворота прогресу через зібрану воду (§5)
- Жодних покарань: смерті немає, з води завжди можна вилізти

## Ще не реалізовано

Язик-гак, планер горловим міхуром, липкі лапки, квак-хвиля, вороги, звук
з живих інструментів. Це наступні кроки прототипу.
