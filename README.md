# 🐸 ЖАБІК: Спадок Росяних Кристалів

> 3D-платформер-колектатон у дусі *Spyro the Dragon* — про жабеня, яке рятує світ, що висихає.

**Жанр:** 3D action-platformer / collectathon
**Аудиторія:** 7+ (сімейна, «легко почати — важко зібрати все на 100%»)
**Камера:** третя особа, вільна орбітальна
**Платформи (ціль):** PC + консолі, керування з геймпада в пріоритеті
**Мова оригіналу:** українська

---

## Пітч на один абзац

Світ **Ставокраю** тримається на **Росяних Кристалах** — застиглих краплях живої води.
Коли давній дух посухи **Сушняк** розбив Велике Свічадо, кристали розлетілися по п'яти
затоплених царствах, а Пращури-жаби засохли в глиняних коконах. Єдиний, хто лишився
мокрим, — жабеня **Кум**, найменша червоночерева кумка зі ставка. Він стрибає, чіпляється
язиком, надуває горловий міхур і планерує над очеретом — щоб зібрати воду світу назад
по краплині.

## Три стовпи дизайну

| Стовп | Що це означає на практиці |
|---|---|
| **Радість руху** | Стрибок → язик-гак → планер зчіплюються в один потік. Пересуватися має бути весело навіть у порожній кімнаті. |
| **Світ як цукерка** | Кожен рівень — компактна коробка з секретами, а не відкритий світ. 8–12 хвилин на проходження, 20+ на 100%. |
| **Жодних покарань** | Смерть коштує кристалів, не прогресу. Гру можна пройти, не вбивши жодного ворога. |
